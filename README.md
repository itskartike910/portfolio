# Portfolio

My personal portfolio showcasing my projects, skills, and experience. Built with Flutter Web for a responsive and modern experience across all devices.

## 🌐 Live Demo

**Check out the live version:** [https://portfolio-kk09.netlify.app/](https://portfolio-kk09.netlify.app/)

## ✨ Features

- **Fully Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern Dark Theme**: Eye-friendly interface with smooth animations
- **Project Showcase**: Detailed cards displaying all my projects with technologies and links
- **Contact Section**: Easy way to reach me with email and social media links
- **Fast & Optimized**: Built with Flutter Web for excellent performance

## 🛠️ Built With

- **Flutter Web** - Cross-platform UI framework
- **Dart** - Programming language
- **Firebase Cloud Functions** - Backend for email functionality
- **Google Fonts** - Beautiful typography
- **Netlify** - Hosting & deployment
